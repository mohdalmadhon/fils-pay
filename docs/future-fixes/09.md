# Audit finding 09: Capture discounts match established settlement rounding

Validated against main `44c2b04`, 2026-10-30. Implemented on `future-fixes`.

## Confirmed problem

At 21 fils, MDR 250 bps and discount 1250 bps, discounting the rounded fee differs from MDR on discounted gross. The Go rule is already the documented settlement and API reconciliation rule.

## Change

Capture events snapshot the charged MDR after the tier. Discount adjustment now credits base MDR minus the shared settlementFeeFils result. Go settlement, its frozen money helpers and fee policy are unchanged. A pending legacy event without a pricing snapshot retains the previous fee-discount contract and is marked legacy-fee-discount. Existing unmapped legacy credits are blocked for review, and completed historical postings are not repriced. Restart API; no schema change.

## Verification

node --import tsx scripts/future-fixes/09.verify.mjs posts an actual capture and adjustment, asserts net fee zero, and calls the Go fee helper for parity. Re-run 06.verify.mjs to retain replay coverage.
