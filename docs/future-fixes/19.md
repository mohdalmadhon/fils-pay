# Audit finding 19: Render signed reconciliation amounts

Validated against main `44c2b04`, 2026-10-30. Implemented on `future-fixes`.

## Confirmed problem

The shared dashboard formatter rejected -1 fil even though reconciliation gaps and ledger/payable positions may be negative, causing rendering to throw.

## Change

The display formatter brands signed integer fils with allowNegative. Validation of non-integer or unsafe amounts remains unchanged. No monetary arithmetic or API contract changes.

## Verification

node --import tsx scripts/future-fixes/19.verify.mjs calls the actual formatter on negative, zero and positive values, and verifies fractional fils still throw.
