# Audit finding 05: Platform volume overflows INT4

Validated against main `44c2b04`, 2026-10-30. Implemented on `future-fixes`.

## Confirmed problem

An actual Go/SQL probe at 2,147,483,640 plus 100 reproduces signed int32 wrap; the tier then disappears.

## Change

Migration 0080 widens the cumulative FILS counter to BIGINT before an int64 worker is deployed. PostgreSQL performs checked BIGINT addition. Existing negative/wrapped history is not guessed: review closed batches with finance before correcting the counter. The migration plan and deployment ordering are included here; the frozen money packages are unchanged.

## Verification

Run node scripts/future-fixes/05.verify.mjs with DATABASE_URL after migration. It updates the singleton only inside a rolled-back transaction and asserts 2,147,483,740 plus the 15-bps tier.
