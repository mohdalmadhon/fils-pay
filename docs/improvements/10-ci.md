# 10: There was no CI

| | |
|---|---|
| **Type** | Engineering process |
| **Status** | Fixed (5 commits, not pushed). Making the checks *required* is a GitHub setting; see below. |
| **Where found** | There was no `.github/` directory: no workflow, no required checks, no dependency updates. Noted in the security review ([`docs/cyper/17`](../cyper/17-open-findings.md), finding 1) and it is how the 10 failing tests in improvements 01–03 sat on `main` unnoticed. |

## Fix

`.github/workflows/ci.yml` runs on every pull request and every push to
`main`:

| Job | What it runs |
|---|---|
| Typecheck and build | `npm ci`, `npm run typecheck` (all workspaces, `db`, `scripts`), `vite build` of the dashboard and the Ops console |
| Tests | A Postgres 16 service: `npm run migrate` on an empty database, `npm run seed`, `npm test` (every workspace and the scripts tests, in sequence) |
| Settlement | The same migrations, then `go vet ./...` and `go test ./...`. The Go version comes from `go.mod`. |
| Dependency audit | `npm run audit:prod` |

`.github/dependabot.yml` opens weekly update PRs for npm, the Go module and
the workflow actions, and CI runs on each of them.

| # | Commit |
|---|---|
| 1 | `ci: typecheck and build on every pull request` |
| 2 | `ci: run the TypeScript tests against a fresh Postgres 16` |
| 3 | `ci: vet and test the Go settlement service against Postgres` |
| 4 | `ci: audit dependencies, open weekly update PRs, document required checks` |
| 5 | `docs: improvement 10, CI` |

## Verified locally

The workflow can only run on GitHub. Its steps were run locally against a new
Postgres 16 database:

| Step | Result |
|---|---|
| `npm run typecheck` | clean |
| `vite build` (web, admin) | both build |
| `npm run migrate` / `npm run seed` | 75 applied / assertions pass |
| `npm test` | **exit 0**: events 4/4, money 40/40, API 533/533, reporting 12/12, web 8/8, scripts 10/10 |
| `go vet ./...` + `go test ./...` | all packages pass |
| `npm run audit:prod` | 0 vulnerabilities |

This is the first fully green run of the whole suite in this repo.
